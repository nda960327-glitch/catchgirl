Proposal · 캐치걸 예약 시스템

전화 안 받아도
예약이 차는 가게

"오늘 돼요?" "몇 시 돼요?" — 하루 수십 번 받던 그 질문이 사라집니다. 캐치테이블처럼 손님이 직접 날짜 → 캐치걸 → 시간을 골라 예약하는, 우리 매장 전용 앱을 1~2주 안에 만들어 드립니다.

제안일 2026. 08. 23 수신 어나더 대표님 제안 노도아 · 010-8256-2255 개발 기간 1~2주
지금의 문제무엇이 바뀌나손님 경험기능왜 저인가일정·비용기능 설명서

직접 디자인한 ‘C’ 머리핀 캐치걸 캐릭터.
앱 아이콘부터 스티커까지 한 세트로 준비되어 있습니다.

01 · 지금, 매장에서 매일 벌어지는 일

예약은 늘 ‘사람 손’으로 받고 있었습니다

영업 중에 울리는 전화, 쌓이는 DM, 수첩에 적은 이름. 잘 돌아가는 것 같아도 매일 같은 질문에 같은 답을 하고 있습니다.

“오늘 ○○ 돼요?”
되는지 확인하려고 장부 보고, 캐치걸한테 물어보고, 다시 전화.
“몇 시에 비어요?”
시간대별로 설명하다 보면 통화 3분. 그 사이 홀은 비어 있습니다.
“저 지난번에 왔었는데…”
누구였는지, 몇 번 왔는지, 누굴 지정했는지 — 기억에만 의존.
  • 수기 장부라 더블부킹이 나고, 취소 연락 없이 안 오는 노쇼는 그냥 손해로 끝납니다.
  • 피크타임에 전화·DM 응대하는 사람이 따로 필요합니다. 그 시간은 접객에 써야 할 시간입니다.
  • 단골이 누구인지, 누가 노쇼 상습인지, 3개월째 안 오는 손님이 누구인지 데이터가 없습니다.
  • 손님 입장에서도 전화가 부담스럽습니다. 새벽에 예약하고 싶어도 방법이 없고, 실명을 말하는 것도 꺼려집니다.
02 · 도입 후

묻지 않아도 되는 가게가 됩니다

손님이 앱을 열면 오늘 누가 출근했고 몇 시가 비었는지 한눈에 보입니다. 마감된 시간은 회색으로 바로 표시되니, 물어볼 이유 자체가 없어집니다.

지금캐치걸 도입 후
전화·DM으로 “되나요, 몇 시 되나요” 응대손님이 앱에서 실시간 빈 시간을 직접 보고 예약. 질문이 사라짐
수첩·카톡에 적는 예약, 더블부킹 위험같은 시간 중복 예약은 시스템이 막음 (동시 접속 5명 테스트 완료). 관리자 캘린더에 자동 정리
노쇼는 그냥 손해예약 확정·방문 1시간 전 카톡 알림으로 노쇼 감소. 노쇼 이력은 고객별로 자동 누적, 3회 이상 경고·블랙 관리
단골 기억은 사람 머릿속방문 횟수·최근 방문일·재방문 수·주로 지정한 캐치걸·메모가 자동 기록. 신규 / 단골 / VIP 등급 자동 부여
피크타임에 응대 인력 1명 고정그 사람이 홀과 접객에 집중. 전화 예약은 관리자 화면에서 10초 만에 등록
손님 연락처·생일·취향은 아무 데도 안 남음닉네임 · 휴대폰 · 이름 · 생년월일 · 성별 · 인스타 · 방문 경로가 고객 DB에 전부 쌓임. 생일 쿠폰 · 타깃 안내 · 재방문 마케팅의 재료
어떤 캐치걸이 인기인지 감으로 판단캐치걸별 예약 수·재방문 유도율·평점·노쇼율이 숫자로 보임
03 · 손님이 느끼는 것

“여기는 내가 단골인 걸 알아봐 주네”

예약이 편한 가게는 많습니다. 캐치걸은 거기서 한 걸음 더 — 내가 좋아하는 사람을 지정해서 예약하고, 앱이 나를 기억해 주는 경험을 줍니다.

📵 전화 안 해도 됩니다
새벽 2시에도, 회의 중에도 30초면 예약 끝. 예약번호와 캘린더 파일까지 바로 받습니다.
💗 좋아하는 캐치걸 지정
사진·소개·태그(#상냥함 #말잘함 #외모귀여움)·후기·평점을 보고 고릅니다. 마음에 들면 찜해두고 다음에 또.
🙈 가입 없이, 닉네임 하나로
휴대폰 번호 + 닉네임이면 바로 시작. 이름·생일·인스타는 원하면 적고, 마이페이지에서 언제든 채울 수 있어 첫 예약 문턱이 낮습니다.
🏅 신규 → 단골 → VIP
5회 방문하면 단골, 10회면 VIP 배지. “3번 더 오면 VIP가 돼요”라는 문구 하나가 재방문을 만듭니다.
💬 후기와 댓글로 소통
다녀온 손님만 후기를 쓰고, 게시판에 남긴 댓글엔 캐치걸이 직접 답글. 예약 전부터 관계가 시작됩니다.
🔔 카톡으로 챙겨 줍니다
예약 확정 · 1시간 전 리마인드 · 취소 안내. 손님은 잊지 않고, 매장은 노쇼가 줄어듭니다.

이미 만들어져 있습니다. 지금 바로 보여드릴 수 있어요

05 · 왜 저와 해야 하나

이 업계를 아는 사람이, 이미 만들어 놓고 제안합니다

외주 개발사는 우리 가게가 어떻게 돌아가는지 모릅니다. 설명하는 데 2주, 고치는 데 또 2주. 저는 다릅니다.

業

현장을 압니다

같은 업계에서 일하고 있습니다. 캐치걸 지정 예약이 왜 필요한지, 노쇼가 어떤 손님한테서 나는지, 피크타임에 뭐가 제일 급한지 — 설명 안 하셔도 압니다. 내부에서 필요한 기능을 먼저 제안해 드릴 수 있습니다.

完

이미 80%가 만들어져 있습니다

기획서만 들고 오는 제안이 아닙니다. 지금 링크를 열면 예약부터 관리자까지 전부 동작합니다. 그래서 1~2주 만에 오픈이 가능합니다.

直

바로바로 수정합니다

중간 대행 없이 저와 직접 소통합니다. “이 문구 바꿔줘”, “이 캐치걸 오늘 휴무로” 같은 요청은 카톡 한 줄이면 당일 반영. 큰 기능도 며칠 단위로 붙습니다.

C

우리 가게 앱처럼 보입니다

직접 디자인한 C 머리핀 캐치걸 캐릭터와 핑크 톤이 기본이고, 원하시면 매장 로고·컬러로 5분 만에 바꿀 수 있습니다. 손님 눈에는 대형 플랫폼이 아니라 어나더 전용 앱입니다.

06 · 일정과 비용

1~2주 안에 오픈, 비용은 모두 협의 가능

보통 이 정도 앱을 외주로 맡기면 기획·디자인·개발을 거쳐 두세 달이 걸립니다. 저는 이미 만들어 둔 것 위에 매장 맞춤만 얹으면 됩니다.

일반 외주 개발사
8~12주 · 1,500~3,000만 원대
  • 기획 미팅 → 화면 설계 → 디자인 → 개발 → 검수
  • 업계 이해 없음, 요구사항 설명에만 수 주
  • 수정 1건당 추가 견적, 답변은 영업일 기준
  • 기능 추가는 별도 계약

1~2주 · 비용 협의
  • 이미 완성된 앱에 매장 정보·캐치걸·근무표만 세팅
  • 카톡 알림톡·쿠폰 등 원하는 기능 골라서 추가

  1. 1~2일차
    세팅

  2. 3~7일차
    맞춤 기능
    카카오 알림톡(확정·1시간 전·취소), 재방문 쿠폰, 그 외 체크하신 기능. 대표님·캐치걸 의견 받아 문구·흐름 다듬기.
  3. 8~10일차
    실전 테스트 · 교육
    실제 예약 데이터로 하루 운영 시뮬레이션. 캐치걸·매니저 30분 교육(관리자 화면은 10분이면 익힙니다).

    오픈 · 밀착 대응
    인스타 링크·QR 배포, 첫 주 현장 피드백 즉시 반영. 이후 유지보수는 협의한 방식으로.

실제 화면으로 보는 캐치걸

아래는 현재 동작 중인 앱을 그대로 캡처한 화면입니다. 합성이 아니라 진짜 데이터(캐치걸 준희·태리·아인, 고객 유나 외)로 돌아가는 모습입니다.

고객 앱

손님 휴대폰에서 보는 화면. 앱 설치 없이 링크·QR로 열립니다.

CUSTOMER 01

홈

열자마자 오늘 출근한 캐치걸이 보입니다. 질문할 필요가 없는 첫 화면.

  • 매장 로고 · 오늘 영업 여부 배지 · 오픈 시간
  • 캐치걸 카드: 사진 · 닉네임 · 평점 · 태그 · 오늘 남은 자리 수 (실시간)
  • 로그인한 손님에겐 “○○님, 다녀온 자리를 기억해 두었어요” 개인화 배너
  • 하단 탭: 홈 · 예약 · 마이
CUSTOMER 02

캐치걸 목록 — “누구와 함께 할까요”

전체 캐치걸을 한눈에. 남은 자리가 적으면 색이 바뀌어 “서두르세요” 신호를 줍니다.

  • 비활성(퇴사·휴직) 캐치걸은 자동으로 숨김
  • 카드를 누르면 프로필로 이동
CUSTOMER 03

캐치걸 프로필

손님이 가장 오래 머무는 화면. 사진과 후기가 예약을 만듭니다.

  • 사진 캐러셀 (스와이프, 최대 10장)
  • 태그 · 소개글 · ♡ 찜 버튼
  • 평점 · 후기 수 · 재방문율 3단 지표
  • 후기 탭: 별점 + 글 + 사진, 손님 등급 배지(단골/VIP), 캐치걸 답글, 신고
  • 하단 고정 [준희 예약하기] 버튼
후기는 실제로 방문 완료한 손님만 쓸 수 있어 신뢰도가 높습니다.
CUSTOMER 03-B

댓글 게시판

예약 전에 가볍게 말을 걸 수 있는 공간. 캐치걸이 직접 답글을 답니다.

  • 누구나 댓글 작성(로그인 필요), 대댓글 1단계
  • 캐치걸/매장 답글은 색이 달라 바로 구분
  • 부적절한 댓글은 관리자가 숨김 처리
CUSTOMER 04

예약 1단계 — 날짜

오늘부터 설정한 기간(기본 14일)까지. 회색 날은 누를 수 없습니다.

  • 매장 정기 휴무 · 캐치걸 개인 휴무 · 근무 없는 요일은 자동 회색 + 사유 표시
  • 상단에 단계 표시 1/3, 선택한 캐치걸 요약
CUSTOMER 05

예약 2단계 — 시간 (실시간)

“몇 시 돼요?”가 사라지는 화면입니다.

  • 30분 단위 슬롯(60분으로 변경 가능), 손가락으로 누르기 좋은 크기
  • 흰색 = 가능 · 회색 줄 = 마감(다른 손님이 선점) · 점선 = 근무 외 · 지난 시간은 비활성
  • 5초마다 자동 갱신 — 다른 손님이 예약하면 내 화면에서도 바로 회색으로
  • 내가 고른 시간이 그 사이 마감되면 “방금 다른 분이 예약했어요” 안내 후 자동 해제
  • 취소 정책 안내 (방문 2시간 전까지)
CUSTOMER 06

예약 3단계 — 확인

입력할 게 거의 없습니다. 닉네임은 자동, 요청사항만 선택 입력.

  • 예약 요약 + 시간 변경 링크
  • 요청사항 (창가 자리, 기념일 등) 200자
  • 노쇼 정책 문구 노출(관리자가 설정)
  • 비로그인 상태면 이 단계에서 휴대폰·닉네임 입력 → 바로 이어서 확정
CUSTOMER 07

예약 완료

캐치걸 캐릭터가 “자리를 비워둘게요”. 작은 성공 애니메이션과 함께.

  • 일시 · 캐치걸 · 닉네임 · 예약번호
  • 캘린더에 추가(.ics) · 내 예약 보기 · 예약 취소
  • 동시에 예약 확정 알림 발송 (현재 콘솔/토스트 → 알림톡 연동 시 카톡으로)
CUSTOMER 08

마이페이지

“앱이 나를 기억한다”는 느낌을 주는 화면. 재방문을 만드는 장치가 모여 있습니다.

  • 닉네임 · 휴대폰 · 등급 배지(신규/단골/VIP) · “3번 더 방문하면 VIP”
  • 내 정보 입력/수정 (이름·생일·성별·방문 경로·인스타·이메일) — 생일 쿠폰·이벤트 안내용
  • 누적 방문 · 예정 건수 · 후기 수
  • 예약 히스토리 예정 / 완료 / 취소 탭 — 각 건에 캐치걸 사진, 예약번호
  • 예정 건 [취소하기], 완료 건 [후기 쓰기]
  • 찜한 캐치걸 · 내가 쓴 후기
CUSTOMER 09

후기 쓰기

완료된 예약에서만 열립니다. 별점 → 한마디 → 사진.

  • 별점 5단계 + 문구 반응(“최고였어요”)
  • 사진 최대 5장, 휴대폰에서 자동 리사이즈(용량 걱정 없음)
  • 등록 즉시 프로필 후기 탭과 평점에 반영
CUSTOMER 10

시작하기 (로그인)

가입 절차가 없습니다. 닉네임과 휴대폰 번호, 두 칸.

  • 필수는 닉네임·휴대폰 두 칸. “추가 정보”를 펼치면 이름·생년월일·성별·방문 경로·인스타그램·이메일
  • 같은 번호면 자동으로 같은 손님으로 인식 → 방문 횟수 이어짐
  • 입력한 정보는 전부 관리자 고객 상세에 쌓여 생일 쿠폰·타깃 안내에 바로 씁니다

캐치걸 전용 화면

각 캐치걸이 본인 계정으로 로그인. 본인 예약만 보입니다.

STAFF 01

내 예약 캘린더

출근하면 오늘 누가 몇 시에 오는지 한 화면에.

  • 14일 날짜 스트립, 휴무·근무 없는 날 회색
  • 이 날의 근무 시간 · 남은 슬롯 · 예약 팀 수
  • 슬롯 타임라인에 손님 닉네임 표시
  • 예약 목록: 시간 · 닉네임 · 휴대폰(바로 전화) · 요청사항 · 상태
관리자가 발급한 ID로만 로그인. 다른 캐치걸 예약·고객 번호는 볼 수 없습니다.
STAFF 02

내 후기 · 댓글

내 평점·후기 수·재방문율을 보고, 손님 후기와 댓글에 직접 답글.

  • 답글 안 단 댓글 개수 뱃지
  • 후기 답글은 프로필에 “캐치걸 답글”로 노출

관리자 화면 (데스크톱 · 태블릿)

매니저·대표님용. 휴대폰에서도 열리지만 PC에서 가장 편합니다.

ADMIN 01

대시보드

출근해서 제일 먼저 여는 화면. 오늘 장사가 한눈에.

  • KPI: 오늘 예약 수(남은 건수) · 오늘 노쇼 · 30일 취소율 · 7일 신규 고객
  • 오늘의 타임라인: 캐치걸 행 × 시간 열 간트 차트. 현재 시각 강조, 상태별 색(확정/완료/노쇼)
  • 주간 예약 추이 라인 차트 · 캐치걸별 예약 점유율 막대 차트
  • 오늘 예약 목록 (요청사항 포함)
  • 우상단 [전화 예약 등록] 바로가기
ADMIN 02

예약 관리 — 리스트

  • 필터: 날짜 · 캐치걸 · 상태 · 고객 닉네임 검색
  • 각 행에 예약번호 · 캐치걸 · 고객(휴대폰 번호, 블랙리스트 표시) · 요청사항 · 상태
  • 한 번 클릭으로 방문완료 / 노쇼 / 취소, 수정(시간·캐치걸 변경), 되돌리기
  • 고객 이름을 누르면 고객 상세로
ADMIN 02-B

예약 관리 — 캘린더 뷰

  • 월간 달력, 날짜별 예약 건수와 캐치걸별 건수 칩(준1 · 태2 …)
  • 날짜를 누르면 그 날 리스트로
ADMIN 02-C

전화 예약 등록

전화로 들어온 예약도 10초면 끝. 손님 앱과 같은 슬롯에 들어가 더블부킹이 나지 않습니다.

  • 캐치걸 · 날짜 · 시간 선택
  • 기존 고객 선택 또는 신규 고객(닉네임·번호) 즉시 생성
  • 관리자 등록은 “관리자 등록” 표시가 남음
ADMIN 03

직원(캐치걸) 관리

  • 왼쪽: 캐치걸 카드 — 활성/비활성, 로그인 ID, 동시 접객 팀 수, 근무 요일, 실적 5종(예약 수 · 방문완료 · 재방문 유도율 · 평균 별점 · 노쇼율)
  • 오른쪽 편집: 프로필 사진 여러 장(대표 지정), 닉네임/실명, 소개, 태그, 동시 접객 인원, 로그인 계정 발급, 요일별 근무 시간, 특정일 휴무
  • 저장 즉시 고객 앱 슬롯에 반영
ADMIN 04

고객 관리 ★

단골과 노쇼를 숫자로 관리하는 화면. 영업의 핵심입니다.

  • 열: 고객(휴대폰 · 이름 · 생일) · 등급 · 방문 횟수 · 최근 방문일 · 취소 · 노쇼 · 재방문 수 · 주 지정 캐치걸
  • 정렬: 재방문 많은 순 · 노쇼 많은 순 · 최근 방문 순 · 취소 많은 순
  • 필터: 단골·VIP / 휴면(3개월 미방문) / 노쇼 이력 / 블랙리스트
  • 노쇼 3회 이상 자동 “노쇼 경고” 배지
ADMIN 04-B

고객 상세

  • 방문/재방문/취소/노쇼/최근 방문 요약
  • 전체 예약 히스토리(후기 포함) · 주로 지정한 캐치걸 순위 · 찜 목록
  • 고객 정보 전체 편집: 휴대폰 · 이름 · 생년월일 · 성별 · 방문 경로 · 인스타그램 · 이메일 — 전화 걸기/인스타 바로가기 링크
  • 관리자 전용 메모(“조용한 대화 선호, 창가 자리”) — 손님에겐 안 보임
  • 블랙리스트 지정 → 해당 손님은 앱 예약 차단
ADMIN 05

후기 · 댓글 관리

  • 신고된 후기가 맨 위 (사유 표시) → 문제 없음 / 숨김
  • 캐치걸 대신 답글 작성 · 답글 수정
  • 댓글 숨김 · 매장 이름으로 답글
ADMIN 06

매장 설정 — 화이트라벨

오른쪽 미리보기를 보면서 바꿉니다. 저장하면 손님 앱이 그 즉시 바뀝니다.

  • 매장명 · 태그라인 · 로고 · 커버 · 메인 컬러(프리셋 + 자유 선택)
  • 오픈/마감 시간 · 슬롯 단위(30/60분) · 예약 가능 기간 · 취소 마감 시간 · 정기 휴무 요일
